# ⚽ Quadro Tático Web

Um quadro tático interativo de futebol feito totalmente em HTML5, CSS e JavaScript Vanilla. Sem necessidade de banco de dados, login ou instalação. 

## Funcionalidades
- Adição de jogadores arrastáveis (Time A e Time B)
- Ferramenta de desenho (Caneta, Borracha, Desfazer) para traçar rotas e táticas
- Chute a gol automático e Sistema de passes entre jogadores
- Alternância de visualização do campo (Horizontal / Vertical)
- Sistema de gravação de jogadas (Grave a movimentação e dê "Play")
- Salvamento no Local Storage (feche o navegador e continue de onde parou)

## 🚀 Como colocar online de graça no seu GitHub

Você pode hospedar este projeto em minutos através do GitHub Pages, tornando-o acessível de qualquer navegador.

### Passo a Passo de Hospedagem (GitHub Pages):

1. **Extraia os arquivos:** Descompacte a pasta ZIP que você baixou. Você deve ver os arquivos `index.html`, `style.css`, `script.js` e este `README.md`.
2. **Acesse o GitHub:** Vá até [github.com](https://github.com/) e faça o login na sua conta.
3. **Crie um novo repositório:** 
   - No canto superior direito, clique no ícone de `+` e selecione **New repository**.
   - Dê um nome para ele, como por exemplo: `quadro-tatico`.
   - Pode deixá-lo como **Public** e clique em **Create repository**.
4. **Faça o Upload dos arquivos:**
   - Na página do repositório recém-criado, clique em **uploading an existing file**.
   - Arraste os arquivos extraídos (`index.html`, `style.css`, etc.) para a área indicada e faça o commit (clique em *Commit changes*).
5. **Ative o GitHub Pages:**
   - No seu repositório, vá na aba **Settings** (Configurações) no menu superior.
   - No menu lateral esquerdo, desça até encontrar a seção **Pages**.
   - Em *Build and deployment*, na parte de **Source**, mantenha *Deploy from a branch*.
   - Em **Branch**, mude de `None` para `main` (ou `master`) e clique em **Save**.
6. **Acesse seu site:**
   - Em alguns minutos (pode levar 1 ou 2 minutinhos), o GitHub fornecerá um link no topo da mesma página de configuração do Pages.
   - O link ficará no formato: `https://WectonSantos.github.io/quadro-tatico/`.
   - Pronto! É só acessar pelo celular ou computador para criar suas jogadas.
